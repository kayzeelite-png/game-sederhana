🎮 Game Kumpulkan Coin

Skor: 0 | Gunakan ← → untuk bergerak dan ↑ untuk melompat

Cara Bermain

  1. Gunakan tombol ← dan → untuk bergerak.
  2. Gunakan tombol ↑ untuk melompat.
  3. Kumpulkan semua coin.
  4. Capai bendera merah untuk menang.

Fitur

  • Karakter dapat bergerak.
  • Karakter dapat melompat.
  • Ada beberapa platform.
  • Ada coin yang bisa dikumpulkan.
  • Ada bendera sebagai tujuan.
